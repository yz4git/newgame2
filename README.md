# BRICK//LAB

A browser-based 3D studded block building simulator rebuilt from scratch for `newgame2`.

## Features

- 1×1, 1×2, 1×3, 1×4, 2×2, 2×3, 2×4 bricks
- Eight colors
- Grid-snapped placement and vertical stacking
- 90° rotation
- Remove mode
- Undo / redo
- Local save / load
- Sample house generator
- One-finger orbit, pinch zoom, tap placement
- iPhone Safari visualViewport + safe-area handling
- PWA support and build-ID cache busting for GitHub Pages

## Development

```bash
npm install
npm run dev
npm run build
```

Public path: `/newgame2/`
